# 932321.bufalov.nikita.lab1

Учебный проект по HTML. Вариант 8

## Описание

Одностраничный сайт-визитка: имя, аватар, навыки, проекты, боковая панель и форма обратной связи.

## Структура

- `<header>` — имя
- `<main>` — картинка, навыки, проекты, форма
- `<section>` «Навыки» — маркированный список
- `<section>` «Проекты» — нумерованный список 
- `<aside>` — любимая кухня и ингредиент
- `<footer>` — копирайт и год
- `<form>` — имя, email, сообщение

## Технологии

- HTML5 
- CSS
